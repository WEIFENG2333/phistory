# 翻译费用审计与续跑预算

审计时间：2026-09-06。已按要求停止 Static 翻译并删除其线上译文。新 API Key 已用于少量真实请求；本轮未执行全量回填，试验译文只保存在忽略目录。当前 Runtime 尚缺 **9,099 段、1,443,349 原文字符**，范围与结构见 [翻译量审计](translation-volume.md)。

## 历史 100 多元花在哪里

现有记录能解释 **¥107.66～115.93** 的当前价等值消耗。主体是很多小批次累积的思考和翻译输出，并非某一段特别长，也不是评测本身占了大头。

| 阶段 | 输入 Token | 输出 Token，含思考 | 当前价等值 |
| --- | ---: | ---: | ---: |
| 历史批量回填，777 批 | 1,345,169 | 3,480,967 | ¥100.16～108.23 |
| 两轮小批试跑，16 批 | 26,437 | 54,469 | ¥1.56～1.76 |
| 留有完整响应的评测，131 次 | 179,999 | 173,060 | ¥5.94 |
| 已知用量合计 | **1,551,605** | **3,708,496** | **¥107.66～115.93** |

777 批回填中：Claude Code 两轮约 ¥79.43～85.76，Codex 约 ¥15.46～16.78，Antigravity 约 ¥5.27～5.69。Claude 的旧日志没有每批 Runtime/Static 标记，无法准确拆出 Static 的账单金额。

删除前 Static 有 5,557 条已译段，其中 4,813 条只用于 Static，另外 744 条也用于 Runtime。Static 独占段约占当时可定位的全部缓存段数 51%，原文字符数约占 43%；**内容占比不能直接当作费用占比**。

原来每批最多 12 段，很多批次远未填满 6,000 字符上限，但每次都会再发送翻译指令并启动思考。777 批平均每批输入约 1,731 Token、输出约 4,480 Token。按当前 GLM-5.3 价格，仅输出就约 **¥97.47**，输入约 ¥2.69～10.76。留有完整响应的 34 次 GLM 评测中，思考占输出 Token 的 **89.4%**；这能说明机制，但不能当作全部历史回填的精确思考比例。

误收的 Mermaid 程序资源有约 295 万待译字符，但其 1,001 段均未命中已保存译文。其他已确认的大型网页/程序资源也没有已保存译文。它们抬高过队列和未来预算，**没有证据证明它们消耗了历史 100 多元**。最大的已记录回填批次输入 3,185、输出 12,740 Token，当前价约 ¥0.38；单个大批不是总费的主体。

## 真实样本：降低思考预算是否可行

采用当前 `zh-CN-10` 提示词和 GLM-5.3，对当前待译队列按批次原文长度分层：小于 800 字符 104 批、800～2,499 字符 493 批、至少 2,500 字符 171 批，共 768 批。每层抽两个不同来源样本，合计 62 段、14,330 原文字符；分别请求 4096、1024 思考预算以及 `enable_thinking=false`。

| 样本 | 段数 | 原文字符 | 4096 预算实际价等值 | 1024 预算实际价等值 |
| --- | ---: | ---: | ---: | ---: |
| OpenClaw：短规则与标题 | 12 | 360 | ¥0.128700 | ¥0.039556 |
| Claude Code：动态环境和日期示例 | 3 | 545 | ¥0.124004 | ¥0.038296 |
| DSH：编辑和授权工具说明 | 12 | 1,706 | ¥0.131448 | ¥0.045404 |
| MiMo：记忆协议与标题 | 12 | 1,103 | ¥0.128428 | ¥0.042468 |
| Hermes：复杂工具和持久记忆说明 | 11 | 5,960 | ¥0.162620 | ¥0.075932 |
| MiniMax Code：技能路由与边界 | 12 | 4,656 | ¥0.156640 | ¥0.102560 |
| 合计 | **62** | **14,330** | **¥0.831840** | **¥0.344216** |

上述费用用每次 API 的输入、输出及缓存命中计算；1024 的 MiniMax 样本发生了一次单段修订，费用已包含。4096 的六批均为一次请求并通过结构校验。

**暂不采用 1024 作为默认配置。** 人工对照原文发现，MiMo 样本中的 `User Message`、`Tools` 和一句普通用户提示被错误标为 `preserved`。JSON Schema 合法不代表翻译质量合格；因此不能把约 ¥41～49 的低预算预测当作可交付报价。

4096 样本的否定、数字、工具标识符和主要条件完整，仍有局部用词需要审读：Hermes 的 `defined end` 被译为“明确结束时间”、`downscaling` 泛化成“缩放”，以及工具替代终端命令的介词关系。对照另一配置的现有输出已经找到更准确译法，无需为这些问题堆全局提示词规则。个别句子直译感仍可改进，不将本轮样本称为“完美翻译”。

请求 `enable_thinking=false` 时，API 实际仍返回了数千乃至上万 reasoning Token；MiniMax 样本两次请求均超时，未得到译文或 usage。不能当作成功关闭思考，更不能据参数名按零思考估价。生产配置保持启用思考、预算 4096。

## 按当前默认配置续跑

估算按“各长度层批数 × 该层样本平均实际费用”加总，避免把固定的每批思考开销误按字符比例摊平。

- 保持每批最多 12 段、6,000 字符、4096 思考预算：约 **¥104.50**，若输入全部不命中缓存约 **¥112.05**。
- 在无缓存估计上预留 20% 给质量修订、重试和样本波动，准备约 **¥135**。
- 这是小样本粗估和预算余量，不是统计置信区间或 API 费用硬上限；未返回 usage 的超时可能产生未知费用。

## 候选优化：每批装 32 段

保持 6,000 字符限制和 4096 思考预算，只把段数上限从 12 改为 32，当前剩余队列的初始请求会由 **768 降到 334**，减少 56.5%。这一配置仅用于实验，尚未修改生产默认值。

| 新样本 | 段数 | 原文字符 | 实际请求 | 当前价等值 |
| --- | ---: | ---: | ---: | ---: |
| OpenClaw 短标题与本地说明 | 32 | 1,366 | 1 | ¥0.156828 |
| MiniMax Code 系统说明 | 32 | 3,818 | 1 | ¥0.173912 |
| Grok 复杂工具参数 | 32 | 5,533 | 1 | ¥0.179200 |
| 合计 | **96** | **10,717** | **3** | **¥0.509940** |

三批结构全部通过，没有自动修订或截断。人工审读中 OpenClaw 和 Grok 未见实质漏译，MiniMax 至少四段残留普通英文（例如说明中的 `review/test/verify/audit` 与标签 `Self`），还有孤立句号，仍需反馈修订。没有这些相同原文的 12 段对照，不能直接认定问题是批次变大造成；同样不能据结构通过就宣称 32 段已通过质量验收。

将 334 个新批次按字符数分为三等份，每层一个样本粗估约 **¥56.78～58.57**；机械增加 20% 为 ¥68～70。但低层样本短于该层平均值，且人工质量修订仍会花钱，因此若之后采用此方案，建议先按 **¥75～85** 准备预算，并边跑边根据 usage 校正。这个数字是候选方案预算，不是已经验收的报价，也不是费用硬上限。

本轮全部实验共 24 次实际 HTTP 尝试，其中 22 次有完整 usage、2 次超时用量未知。已知消耗按当前价格约 **¥2.80**，包含一个连通性样本、六组预算对照、一次自动修订和三个大批样本；未知超时不能算免费。未额外调用模型作自动评分，未启动全量回填。

## 用量记录与核算口径

`phistory translate` 默认将逐请求记录写入 `.phistory-cache/translation-usage.jsonl`，也可用 `--usage-log PATH` 指定。记录 Agent、模型、提示词版本、请求的思考预算、真实原文段 ID、段数、保护后的字符数、请求 ID、耗时、HTTP/连接状态、纠错轮次和原始 `usage`。不记录 Key、请求正文或完整模型回复。

同一批的 HTTP 重试逐次记录；模型修订只记录重新发送的失败段。即使结构校验不通过，已发生的模型用量仍留在日志。没有 usage 就明确记为未知，不能当成免费请求。

```bash
uv run python scripts/summarize_translation_usage.py \
  .phistory-cache/translation-usage.jsonl \
  --model zai-org/GLM-5.3 \
  --input-price 8 --cached-input-price 2 --output-price 28
```

汇总按响应 ID 去重，分别统计输入、缓存输入、输出、思考、失败和修订调用。缓存输入是输入的子集，思考是输出的子集，**不重复加算**。单价由参数提供，避免把会变化的价格硬编码进业务代码。CI 将日志作为 `translation-usage` artifact 保存 30 天。

本报告的历史重建只取每个独立回填日志最后的累计数；完整评测响应按 response ID 去重，没有叠加进度累计、外层汇总或同一原始响应。历史评测还存在 9 次未返回 usage 的超时，旧回填缺缓存明细；旧缓存未知部分的价差按全命中到全未命中列区间。

采用 [SiliconFlow 官方价格](https://siliconflow.cn/pricing)：GLM-5.3 输入 ¥8/百万、缓存输入 ¥2/百万、输出 ¥28/百万；DeepSeek-V4-Pro 输入 ¥12/百万、缓存输入 ¥1/百万、输出 ¥24/百万。它们是审计时的公开价格。历史真实单价、账户优惠和供应商最终扣款仍以账单为准；旧的余额查询接口本次返回 HTTP 410，未获取可用于前后核账的余额。

完整历史证据索引、逐样本译文、usage 与估算数据位于忽略目录 `.phistory-cache/translation-cost/`，公开文档只保留汇总与必要质量例子。
